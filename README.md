# Funniest Forecast for a City That Isn't — Mizzlewick

A one-line entry for the make.fun bounty of the same name. The
forecast for the invented city of Mizzlewick: rain at 3pm, 4pm and
5pm, as the same cloud keeps circling the block. One stubborn cloud,
booked in by the hour — the joke is the weather itself, delivered in
the flat phrasing of an official bulletin.

Running `python3 main.py` validates the line (one line, 1–120
characters, names the invented city) and writes it to
`/output/entry.txt`. The file holds exactly those 81 characters,
with no trailing newline. The line was picked by a three-model
free review panel (Groq): two of three votes for Mizzlewick, against
one for the Yesterton runner-up.
